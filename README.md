# Muhammad Ali, portfolio

Run it:
    npm install
    npm run dev

Edit content: `src/data.js` (about, skills, projects, contact).
Add a project: copy an object in `projects`, change the fields.
SMARTI screenshots: put 6 images in `public/screens/` named smarti-1.png ... smarti-6.png.
Any other project screenshot: put the file in `public/screens/` and add it to that project's `shots`.
Deploy: push to GitHub and import the repo in Vercel (framework: Vite).

Hero photo: put your photo at `public/me.png`. A transparent-background cutout (remove.bg) looks best; the bottom fades out automatically.

Tanki Wala screenshots: save 7-10 phone screens as public/screens/tanki-1.jpg ... tanki-10.jpg (any number up to 10; missing ones are skipped automatically).
New project: copy an object in the `projects` array in src/data.js.
